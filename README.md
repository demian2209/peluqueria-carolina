# Peluquería Carolina - Sistema Web de Reservas

Plataforma digital integral para la gestión de reservas, catálogo de servicios, automatizaciones y asistencia conversacional con Inteligencia Artificial para **Peluquería Carolina**.

---

## 🛠️ Arquitectura y Tecnologías

| Capa / Componente | Tecnología |
| :--- | :--- |
| **Frontend** | React + Next.js (JavaScript) + CSS Nativo |
| **Backend** | Node.js + Express (JavaScript) - REST API |
| **Base de Datos & Auth** | Supabase (PostgreSQL) + Supabase Auth |
| **Automatización** | n8n (Local / Railway) |
| **Inteligencia Artificial** | Google Gemini API (Chatbot) |
| **Mensajería & Notificaciones** | Twilio WhatsApp + Servicio SMTP / Email |
| **Hosting** | Vercel |

---

## 📁 Estructura del Proyecto

```text
peluqueria-carolina/
│
├── frontend/          # Aplicación React/Next.js (Mobile-First, CSS Nativo)
├── backend/           # API REST independiente con Node.js + Express
├── n8n/               # Workflows de automatización (notificaciones, recordatorios)
├── docs/              # Documentación técnica, diagramas y guías
├── peluqueria/        # Maqueta estática HTML de referencia inicial
├── estilos/           # CSS nativo del diseño base de la One Page
└── README.md          # Documentación general del proyecto
```
